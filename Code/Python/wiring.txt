==================================
              WIRING
==================================

----------------------------------
      POWER & I2C SHARED BUS
----------------------------------
* Note: SDA (Pin 3) and SCL (Pin 5) are shared across 
  the VL53L1X, IMU #1, and IMU #2 in parallel.

----------------------------------
             VL53L1X
----------------------------------
VCC --> Pin 1 / 3.3V
GND --> Pin 9 / GND
SDA --> Pin 3 / GPIO 2
SCL --> Pin 5 / GPIO 3

----------------------------------
         IMU #1 (Hand Back)
----------------------------------
VCC --> Pin 1 / 3.3V
GND --> Pin 6 / GND
SDA --> Pin 3 / GPIO 2
SCL --> Pin 5 / GPIO 3
AD0 --> Pin 6 / GND          (Sets I2C Address to 0x68)

----------------------------------
        IMU #2 (Finger Tip)
----------------------------------
VCC --> Pin 1 / 3.3V
GND --> Pin 14 / GND
SDA --> Pin 3 / GPIO 2
SCL --> Pin 5 / GPIO 3
AD0 --> Pin 1 / 3.3V         (Sets I2C Address to 0x69)

----------------------------------
     MOTOR / TRANSISTOR / DIODE
----------------------------------
----TRANSISTOR (NPN / e.g. PN2222)
EMITTER   --> Pin 20 / GND
BASE      --> 1K R
1K R      --> Pin 11 / GPIO 17
COLLECTOR --> MOTOR NEG / DIODE ANODE

----DIODE (Flyback)
CATHODE   --> Pin 2 / 5V  (5V provides stronger vibration than 3.3V)
ANODE     --> COLLECTOR / MOTOR NEG

----MOTOR (ERM Vibration Coin)
POS       --> Pin 2 / 5V  (Connected to Diode Cathode)
NEG       --> COLLECTOR / DIODE ANODE
