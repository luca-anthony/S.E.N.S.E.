==================================
        PICO 2 W WIRING CHART
==================================

----------------------------------
      POWER & I2C SHARED BUS
----------------------------------
* I2C Bus: Using I2C0 hardware bus.
  - SDA (GP4) and SCL (GP5) go to the VL53L1X.
* Power Rails:
  - 3.3V Rail: Pin 36 (3V3 OUT)
  - 5V Rail: Pin 40 (VBUS - raw USB 5V for motor)
  - GND Rail: Any GND pin (Pins 3, 8, 13, 18, 23, 28, 33, 38)

----------------------------------
              VL53L1X
----------------------------------
VCC --> Pin 36 / 3V3 OUT
GND --> Pin 3  / GND
SDA --> Pin 6  / GP4 (I2C0 SDA)
SCL --> Pin 7  / GP5 (I2C0 SCL)

----------------------------------
      FLEX SENSOR (Ring Finger)
----------------------------------
PIN 1 --> Pin 36 / 3V3 OUT
PIN 2 --> Pin 31 / GP26 (ADC0) & 10K Resistor
10K R --> Pin 33 / AGND
(No polarity. Printed side faces the finger.)

----------------------------------
      MOTOR / TRANSISTOR / DIODE
----------------------------------
----TRANSISTOR (NPN / e.g. PN2222)
EMITTER   --> Pin 18 / GND
BASE      --> 1K Resistor
1K R      --> Pin 22 / GP17 (PWM control)
COLLECTOR --> MOTOR NEG / DIODE ANODE

----DIODE (Flyback)
CATHODE   --> Pin 40 / VBUS (5V USB Power)
ANODE     --> COLLECTOR / MOTOR NEG

----MOTOR (ERM Vibration Coin)
POS       --> Pin 40 / VBUS (Connected to Diode Cathode)
NEG       --> COLLECTOR / DIODE ANODE

----------------------------------
            STATUS LED
----------------------------------
ANODE (+) --> 220Ω Resistor
220Ω R    --> Pin 24 / GP18
CATHODE(-)--> Pin 23 / GND
